# Chaves de Acesso API

A aba **Chaves de Acesso API** permite criar tokens para integrações externas que consomem a API do Ducke CRM em nome da operação. Novas chaves usam o prefixo `ducke_` (ex.: `ducke_a1b2…`).

<img src="/prints/setup-user-tokens.png" alt="Tela de chaves de acesso API no setup" style={{ borderRadius: '0.5rem' }} />

## Como acessar

1. Abra **Configuração** no menu.
2. Selecione a aba **Chaves de Acesso API**.

## Criar uma chave

1. Clique em **Adicionar Chaves de Acesso API** (botão no topo).
2. Informe um **nome** descritivo (ex.: *Integração ERP*, *Webhook interno*).
3. Confirme — o token completo (com prefixo `ducke_`) é exibido **uma única vez**.
4. Use **Copiar** no diálogo, guarde em local seguro e confirme **Já copiei**.

<Callout type="warning">
  Trate cada chave como senha. Depois de fechar o diálogo, o secret completo não pode ser recuperado. Se perder a chave, exclua-a e crie outra. Não compartilhe em chats públicos nem commite em repositórios.
</Callout>

## Gerenciar chaves existentes

A tabela lista **Nome**, preview mascarado da **Chave de Acesso** (início e fim, ex.: `ducke_abcd…wxyz`) e **Ações**:

- **Editar:** altera o nome identificador.
- **Excluir:** revoga o acesso imediatamente.

Não há botão para copiar o secret completo a partir da lista — apenas o preview.

## Quando usar

- Automações que criam ou atualizam leads via API.
- Integrações com ERP, BI ou ferramentas internas.
- Scripts de migração ou sincronização sob demanda.

## Segurança

- Revogue chaves não utilizadas.
- Crie uma chave por integração para facilitar auditoria.
- Restrinja quem tem permissão de escrita nesta aba.
