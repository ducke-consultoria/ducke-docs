# Problemas Técnicos

Aqui você encontrará soluções para problemas técnicos comuns do Ducke CRM.

## Apareceu o aviso "Uma nova versão do Ducke está disponível"

Esse aviso surge no canto da tela quando publicamos uma atualização do Ducke CRM enquanto você está com ele aberto. A aba continua funcionando com a versão antiga até ser recarregada.

1. Termine o que estiver fazendo (por exemplo, salve o formulário aberto): o Ducke nunca recarrega a página sozinho.
2. Clique em **Atualizar** no aviso para carregar a versão nova.

O aviso aparece uma única vez por aba e fica na tela até você agir. O Ducke confere se há versão nova a cada 5 minutos e sempre que você volta para a aba.
