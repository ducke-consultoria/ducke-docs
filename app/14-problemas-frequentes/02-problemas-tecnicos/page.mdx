# Problemas Técnicos

Aqui você encontrará soluções para problemas técnicos comuns do Ducke CRM.

## Apareceu o aviso "Uma nova versão do Ducke está disponível"

Esse aviso surge no canto inferior esquerdo da tela quando publicamos uma atualização do Ducke CRM enquanto você está com ele aberto. A aba continua funcionando com a versão antiga até ser recarregada.

<img src="/prints/app-update-notice.png" alt="Aviso de nova versão do Ducke com o botão Atualizar no canto inferior esquerdo da tela" style={{ borderRadius: '0.5rem' }} />

1. Termine o que estiver fazendo (por exemplo, salve o formulário aberto): o Ducke nunca recarrega a página sozinho.
2. Clique em **Atualizar** no aviso para carregar a versão nova.

O aviso aparece uma única vez por aba e fica na tela até você clicar em **Atualizar**: ele não tem botão de fechar. O Ducke confere se há versão nova a cada 5 minutos e sempre que você volta para a aba.
